Event-to-category table (event_categories.yaml)

The table holds facts about Windows and Sysmon event ids: which category each event belongs to.
It is generated by devtools/knowledge/import_event_categories.py from the sources below. The
generated file says where every row came from.

- pySigma pipelines pysigma-pipeline-windows 2.0.1 and pysigma-pipeline-sysmon 2.0.0 (SigmaHQ),
  licensed under the GNU Lesser General Public License v2.1 only
  (https://www.gnu.org/licenses/old-licenses/lgpl-2.1.html). Their wheels are kept in
  devtools/knowledge/pinned/ and are read as data: nothing from them is imported or run.

- The Elastic Windows Security ingest pipeline, security_standard.yml, in elastic/integrations at
  commit 59aa0e901d5683cb933859bb21bf4da590400e94, licensed under the Elastic License 2.0
  (https://www.elastic.co/licensing/elastic-license). The pipeline is not redistributed here. The
  importer caches it locally (gitignored, devtools/knowledge/pinned/cache/) after checking its
  SHA-256, and the table keeps only the rows for the authentication category and for event 4672
  (special privileges assigned to a new logon), as event id to category pairs.

- Windows provider manifests (WinRM, Task Scheduler, Windows Defender, PowerShell, Security-Auditing),
  exported from Windows 11 build 10.0.26200.9711 with wevtutil and kept in
  devtools/knowledge/pinned/manifests/. They give the category of the WinRM, Task Scheduler and Defender
  events, and which provider logs each event of a channel. Only event ids, task names, channel names and
  message phrases are read from them.

Hayabusa table (hayabusa_fields.yaml)

The table says how a Hayabusa timeline row reads back as its event: the channel each abbreviation
names, the event field each details label shows, and the original form of the values Hayabusa rewrites.
It is generated by devtools/knowledge/import_hayabusa_fields.py from the hayabusa-rules repository
(Yamato Security, https://github.com/Yamato-Security/hayabusa-rules) at commit
04af3d207cae784183e0e5e82c1132ee866bbd67, released under the Detection Rule License 1.1
(https://github.com/SigmaHQ/Detection-Rule-License). No rule is redistributed: the table keeps the
abbreviations, the label-to-field pairs of the details templates and the value rewrites.
